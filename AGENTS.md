# Working on Notebook

A bounded, local prototype of a Goodnotes-like course notebook with peer knowledge. Read `docs/superpowers/specs/2026-11-02-notebook-v2-design.md` (current; the 11-01 spec/plan are superseded) `docs/HANDOFF.md` and `docs/PROGRESS.md` before changing behavior. User decisions outrank earlier proposals. ClassFlowAI is reference-only; this repo imports none of its runtime.

- Node >=24, npm with the checked-in lockfile, poppler-utils. `npm ci`, `npm run seed -- <zip|folder>`, `npm run dev`.
- Run `npm run check` and `npm run test:e2e` before reporting changes as working. E2E uses `e2e/mock-llm.mjs`; never point tests at the live provider.
- Live provider configuration (official DeepSeek, `deepseek-flash`, multimodal) belongs in ignored `.env`; uploads and the database belong in ignored `data/`. Never commit credentials or runtime data.
- Students can take several courses; every course-scoped read/write must check enrollment (`x-course-id` header + lecture/fragment course). Never leak lectures, notes or links across courses.
- Demo identities are explicitly not authentication. Keep the server on loopback.
- No RAG/embeddings by user decision: prompts carry the whole lecture (slide digests + visible classmate fragments). Model citations must be validated server-side against the refs actually supplied.
- Student ink and text are never modified by AI. Suggestions are added only on explicit "Add to my notes", as separate `annotation` items that are excluded from page rendering for indexing, so generated text is never republished as peer evidence.
- Index results are written only if the page revision is unchanged; annotation-only edits must not trigger a new model call (content hash).
- Sharing is automatic and **not** user-reversible in the demo (user decision, Nov 4): there is no Stop sharing, no Manage sharing, and no sharing routes. The AI's own reasons (`unclear`, `unlinked`, `on_slide`) are the only thing that keeps an item private; `withheld` stays dormant so author control can return later. The join/create dialogs still explain that notes are shared, more so now that it cannot be undone. Notes that merely restate the slide are not shared.
- Library layout (user decision, Nov 4): **one free file tree per course**. A course is joined, not created as a folder. Two ordinary folders are seeded once per student per course — **Lectures** (holding the official decks) and **Quizzes** — and are renameable, deletable and movable like any folder; deleting a folder moves its contents up. **My notes** and **All files** are smart views above the tree, not folders. Everything a student owns lives in this tree, including the lecture decks: they keep their `L#`/`PDF` badge and ✎ count wherever they are filed. Notes never move across courses. No add buttons for notebooks/PDFs: PDFs are dropped in, and notebooks/folders come from long-press (touch/pen) or right-click menus; "New folder" is the only button. Tablet is the primary device: every action must work by touch (long-press menu, long-press drag, Move to…).
- Suggestions stay quiet: the panel is closed by default and a small margin marker beside the page is the only indicator. A card opens in place at the gap; nothing covers the page.
- Peer knowledge reaches a student through the **course knowledge base**, never as raw fragments: the merge job groups notes into `knowledge_entries` with an AI summary, single-source entries keep the note verbatim, and disputed entries are excluded from suggestions and prompts. Sources are never listed; cards carry a neutral line ("From 3 classmates' notes", "From slide 12", "AI explanation").
- The merge and check job runs when the student **leaves** the notebook (`POST /api/notebooks/:id/close`, plus a 10-minute sweep for tabs that never closed). A slide whose notes did not change costs no model call.
- A note replaced by a re-read is **superseded, not deleted**: its row stays so a citation already in someone's notes still resolves.
- Fragments are shared only when the transcription and the slide link are both confident (`SHARE_THRESHOLD`); others stay private and visible to the author.
- Quiz answers must be supported by an official slide; questions without a valid slide citation are dropped. There are no reliability labels anywhere: no "unverified", no "Official slides / AI interpretation" basis chips.
- Missing AI configuration must produce a clear error, never fabricated content.
- Mock-provider tests establish transport and control flow only; model quality needs representative inputs and human evaluation.
- `npm run dev` watches both halves: Vite (polling, left on because native watch handles ran out on this workstation once) and the API via `tsx watch`. Use `npm run dev:local` (4312/5174) when the public service is running, since it already holds 4310.
- The public demo `notebook.zh-thomas.party` runs as `notebook.service` from this same working copy via `npm run serve`, which watches and rebuilds. **Every change here is live on the public page within seconds** — no deploy or restart. Keep the tree presentable, and restart the service only after editing `.env`.
